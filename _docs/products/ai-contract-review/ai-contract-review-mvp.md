# AI 合同审核 MVP 方案

> 一人公司第一款变现产品

---

## 一、产品定位

### 1.1 一句话描述

**上传合同 → AI 自动标注风险 → 一键生成审核报告**

### 1.2 目标用户

| 用户画像 | 痛点 | 付费意愿 |
|----------|------|----------|
| 创业者/个体户 | 不懂法律，怕踩坑 | 高（¥29-99/份） |
| 中小企业主 | 请不起法务，审核慢 | 高（¥199-499/月） |
| 采购/销售 | 合同量大，审核不过来 | 中（¥99-299/月） |
| 律师助理 | 重复性工作多，效率低 | 中（¥199-499/月） |

### 1.3 核心价值

```
❌ 传统方式：等法务 2-3 天，或请律师 ¥1000+
✅ AI 审核：3 分钟出结果，¥9.9 起

时间缩短 100 倍，成本降低 10 倍
```

### 2.2 风险识别能力

| 风险类型 | 识别内容 | 严重程度 |
|----------|----------|----------|
| **主体风险** | 公司信息不完整、主体不适格 | 🔴 高 |
| **金额风险** | 金额模糊、支付条款不明 | 🔴 高 |
| **违约风险** | 违约责任不对等、惩罚过重 | 🔴 高 |
| **期限风险** | 履行期限不明、自动续约陷阱 | 🟡 中 |
| **管辖风险** | 管辖法院不利、仲裁条款 | 🟡 中 |
| **保密风险** | 保密范围过宽、违约金过高 | 🟡 中 |
| **知识产权** | 权属约定不明、侵权风险 | 🟡 中 |
| **解除风险** | 解除条件苛刻、通知期限短 | 🟢 低 |

### 2.3 审核报告结构

```
════════════════════════════════════════════════
              AI 合同审核报告
════════════════════════════════════════════════

合同名称：XXX 服务合同
上传时间：2026-03-27 20:15
审核时长：2 分 30 秒

────────────────────────────────────────────────
📊 审核概览
────────────────────────────────────────────────
• 合同页数：8 页
• 条款总数：32 条
• 风险数量：5 个
  - 🔴 高风险：2 个
  - 🟡 中风险：2 个
  - 🟢 低风险：1 个
• 综合评分：72/100

────────────────────────────────────────────────
🔴 高风险条款（需重点关注）
────────────────────────────────────────────────

【第 5 条 违约责任】
原文："乙方违约需支付合同总额 30% 的违约金"

⚠️ 风险分析：
违约金比例过高（30%），远超法律保护范围（通常不超过实际损失的 30%）。
若发生纠纷，法院可能调低，但仍有较大风险。

💡 修改建议：
建议调整为"支付合同总额 10% 的违约金"或"赔偿实际损失"。

────────────────────────────────────────────────
🟡 中风险条款（建议优化）
────────────────────────────────────────────────

【第 8 条 争议解决】
原文："争议提交甲方所在地人民法院管辖"

⚠️ 风险分析：
管辖法院约定对乙方不利，异地诉讼成本高。

💡 修改建议：
建议改为"被告所在地"或"合同履行地"法院管辖。

────────────────────────────────────────────────
✅ 审核结论
────────────────────────────────────────────────

本合同存在 2 处高风险条款，建议修改后再签署。
主要风险集中在违约责任和争议解决条款。

建议与对方协商：
1. 降低违约金比例
2. 调整管辖法院
3. 明确付款条件和时间

              由 AI 合同助手 生成
         https://cloudmesh.top/contract
```

## 三、技术架构

### 3.1 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                    AI 合同审核架构                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  前端                                                        │
│  ├── Web 页面（Next.js）                                    │
│  ├── 上传组件（拖拽/点击）                                   │
│  ├── 预览组件（PDF 查看）                                   │
│  └── 报告展示（高亮标注）                                    │
│                                                             │
│  ─────────────────────────────────────────────────────────  │
│                                                             │
│  后端                                                        │
│  ├── API 层（FastAPI/Node.js）                              │
│  ├── 文件处理（PDF 解析、OCR）                               │
│  ├── 合同分析（LLM 调用）                                   │
│  └── 报告生成（模板渲染）                                    │
│                                                             │
│  ─────────────────────────────────────────────────────────  │
│                                                             │
│  AI 层                                                       │
│  ├── 文本提取（OCR）                                        │
│  ├── 条款分割（结构化解析）                                  │
│  ├── 风险识别（LLM 分类）                                   │
│  └── 建议生成（LLM 生成）                                   │
│                                                             │
│  ─────────────────────────────────────────────────────────  │
│                                                             │
│  存储                                                        │
│  ├── 合同文件（OSS/S3）                                     │
│  ├── 审核记录（SQLite/PostgreSQL）                          │
│  └── 用户数据（SQLite）                                     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 技术选型

| 层级 | 技术 | 理由 |
|------|------|------|
| **前端** | Next.js + Tailwind | 快速开发，SEO 友好 |
| **后端** | FastAPI | Python 生态，AI 集成方便 |
| **OCR** | PaddleOCR / 百度 OCR | 中文效果好 |
| **LLM** | 通义千问 / DeepSeek | 成本低，效果好 |
| **存储** | SQLite + 阿里云 OSS | 简单够用 |
| **部署** | 阿里云服务器 | 现有资源复用 |

### 3.3 核心流程

```
用户上传合同
    ↓
OCR 文本提取
    ↓
条款分割（正则 + LLM）
    ↓
逐条风险分析（LLM）
    ↓
汇总生成报告
    ↓
返回给用户
```
