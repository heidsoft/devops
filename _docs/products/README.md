## 📂 产品列表

### [智能补货助手](smart-replenishment/)

> AI 销量预测 + 对话式补货建议，帮零售小店省时省力

- 打通收银系统 → AI 预测销量 → 一键生成补货单 → 微信推送
- 目标市场：1500万有收银系统的店铺
- 定价：免费版 / ¥99/月专业版 / ¥299/月企业版

### [ClawOps ITSM](clawops/)

> 企业级 IT 运维管理平台，多租户 + 插件化架构

- 支持 Prometheus / Zabbix / ELK 等多种技术栈
- 对话式操作，降低 ITSM 使用门槛
- 企业版路线图进行中

### [AI 合同审核 MVP](ai-contract-review/)

> 一人公司第一款变现产品

- 上传合同 → AI 自动标注风险 → 一键生成审核报告
- 3 分钟出结果，¥9.9 起
- MVP 已完成
