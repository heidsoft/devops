## 一句话介绍

**打通收银系统 → AI 预测销量 → 一键生成补货单 → 微信推送给老板**

---

## 核心功能

| 功能 | 说明 |
|------|------|
| 销量预测 | AI 分析历史销售，预测未来 7 天销量 |
| 智能补货 | 基于预测 + 库存，自动生成补货建议 |
| 微信推送 | 补货单直接推送到微信，不用打开 App |
| 对话式查询 | "今天该进什么货？" — 自然语言查询 |
| 多店铺管理 | 连锁店统一管理，库存一目了然 |
