## storage/ 从头到尾彻底解析哈希表算法.md 精华

哈希表（Hash Table）核心知识点：

**哈希函数设计原则：**
- 确定性：相同输入永远产生相同输出
- 高效计算
- 均匀分布

**冲突解决方法：**
- 开放寻址法（Open Addressing）
  - 线性探测：`h(k,i) = (h(k) + i) mod m`
  - 平方探测：`h(k,i) = (h(k) + c1·i + c2·i²) mod m`
  - 双重哈希：`h(k,i) = (h1(k) + i·h2(k)) mod m`
- 链地址法（Separate Chaining）

**负载因子（Load Factor）：**
- α = n/m（元素数 / 槽数）
- 一般控制在 0.6~0.75 左右性能最优
